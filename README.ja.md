# music-kanko-dx

福井の観光情報を提供するミュージックプレーヤーアプリです。

## 機能
- 音楽再生
- 観光情報の表示
- プレイリストのシャッフル

## 必要環境
Deno 環境が必要です。

## 使い方
```sh
deno -A https://code4fukui.github.io/music-opendata-fukui/download.js 9da471f6-0d33-4b2d-bbc1-4712fa3a7fb0
```
で音楽データをダウンロードし、`index.html`を起動します。

## データ・API
[music-opendata-fukui](https://github.com/code4fukui/music-opendata-fukui) のオープンデータを使用しています。
