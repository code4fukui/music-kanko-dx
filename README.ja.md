# music-kanko-dx

AI生成音楽をフィーチャーした「観光DX」(Tourism DX)プレイリスト用の、自己完結型Webベース音楽プレイヤーです。このプロジェクトはサーバーを必要とせず、Webブラウザ上で直接動作します。

## デモ

**[▶️ ライブデモ](https://code4fukui.github.io/music-kanko-dx/)**

ユーザーインターフェースは3つの主要なパネルで構成されています。楽曲のプレイリスト、アルバムアートとトラック情報を表示する中央のプレイヤー、そして歌詞パネルです。ページの背景には、現在再生中の楽曲のアルバムアートをぼかした画像が使用されます。

![music-kanko-dxプレイヤーインターフェースのスクリーンショット](https://user-images.githubusercontent.com/10928/270018151-5121b61b-9993-4710-9289-e1377855b76b.png)

## 機能

- **Webベースのプレイヤー**: 最新のWebブラウザで動作する、シンプルでエレガントな音楽プレイヤー。
- **動的なUI**: アルバムアート、楽曲のメタデータ（プロンプト、タグ）、および歌詞全体を表示します。
- **Media Session APIの統合**: OSネイティブのメディアコントロールをサポートし、ロック画面、通知センター、またはスマートウォッチやカーステレオなどの接続デバイスから再生を制御できます。
- **自己完結型**: 初回のデータダウンロード後は、プレイヤーとすべてのアセットをオフラインで実行できます。
- **依存関係ゼロ**: プレイヤー自体はVanilla HTML、CSS、JavaScriptのみで構築されています。

## はじめに

このプロジェクトをローカルで実行するには、まず音楽と画像のアセットをダウンロードする必要があります。

### 前提条件

- ダウンロードスクリプトを実行するには、[Deno](https://deno.land/)がインストールされている必要があります。

### セットアップ

1. **リポジトリのクローン:**
    ```sh
    git clone https://github.com/code4fukui/music-kanko-dx.git
    cd music-kanko-dx
    ```

2. **プレイリストのアセットをダウンロード:**
    プロジェクトのルートディレクトリで以下のコマンドを実行します。このスクリプトは、必要なすべての音声および画像ファイルをダウンロードし、`playlist.json`ファイルを作成します。
    ```sh
    deno run -A https://code4fukui.github.io/music-opendata-fukui/download.js 9da471f6-0d33-4b2d-bbc1-4712fa3a7fb0
    ```

3. **プレイヤーを開く:**
    Webブラウザで`index.html`ファイルを開き、音楽プレイヤーを起動します。

## データ

このプレイリストの音楽、歌詞、アートワークは、`music-opendata-fukui`プロジェクトから提供されています。ダウンロードスクリプトは、プレイリストID `9da471f6-0d33-4b2d-bbc1-4712fa3a7fb0` に関連付けられたアセットを取得します。

- **データソース**: [music-opendata-fukui](https://github.com/code4fukui/music-opendata-fukui)

楽曲は元々Suno AIを使用して生成されたものです。
